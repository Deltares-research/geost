    "# Creating thickness maps from GeoTOP\n",
    "\n",
    "In this example, we will retrieve GeoTOP from the OpenDAP server for an area around Delft and visualize the thickness of several geologic criteria to gain a quick insight into how the subsurface in this area is built up.\n",
    "\n",
    "First, we import GeoST and load the GeoTOP data for the area around Delft."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "fb46f0e2",
   "metadata": {},
   "outputs": [],
   "source": [
    "import geost\n",
    "\n",
    "geotop = geost.read_geotop_from_opendap(bbox=(80_000, 442_000, 89_000, 450_000))\n",
    "print(geotop)"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "dbd5f4e1",
   "metadata": {},
   "source": [
    "As you can see, the data is an `xarray.Dataset` containing all the model variables of GeoTOP. With GeoST's Xarray extension, we can use the [`get_thickness`](../api_reference/generated/geost.models.model_dataset.ModelDataset.get_thickness.rst) method to retrieve thickness maps based on different criteria.\n",
    "\n",
    "First, we would like to determine the total thickness of clay layers in the area. Let's load the lithological metadata for GeoTOP and check the encodings for the different lithologies."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "5a3530fc",
   "metadata": {},
   "outputs": [],
   "source": [
    "lithok_codes = geost.bro.geotop_lithok_units()\n",
    "lithok_codes"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "e2879862",
   "metadata": {},
   "source": [
    "We can derive a thickness map of clay by selecting the `\"k\"` lithology and plotting the result."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "00e5bed2",
   "metadata": {},
   "outputs": [],
   "source": [
    "thickness_clay = geotop.gst.get_thickness(lithok_codes.select_unit(\"k\"))\n",
    "thickness_clay.plot.imshow(\n",
    "    x=\"x\", vmin=0, vmax=20\n",
    ")  # Make sure to set the x-axis for proper visualization"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "6f2cda6a",
   "metadata": {},
   "source": [
    "This shows the total thickness of all clay layers combined in the GeoTOP model. However, we may only be interested in Holocene clay layers. In that case, we need to add this condition to refine the selection.\n",
    "\n",
    "Let's load the stratigraphic metadata as well and add the Holocene stratigraphy to the condition. We can do this by selecting all Holocene units with the [`get_holocene_units`](../api_reference/generated/geost.bro.geotop.GeotopUnits.get_holocene_channel_units.rst) method and combining this with the selection from `lithok_codes` using the logical `&` operator."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "df6b1a44",
   "metadata": {},
   "outputs": [],
   "source": [
    "strat_units = geost.bro.geotop_strat_units()\n",
    "\n",
    "thickness_clay_holocene = geotop.gst.get_thickness(\n",
    "    strat_units.get_holocene_units() & lithok_codes.select_unit(\"k\")\n",
    ")\n",
    "thickness_clay_holocene.plot.imshow(x=\"x\", vmin=0, vmax=20)"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "aaefa674",
   "metadata": {},
   "source": [
    "As you can see, `GeotopUnits` instances can be used as conditions in methods such as `get_thickness`. It is also possible to use the logical `&` (and) and `|` (or) operators to combine selections and create the desired condition.\n",
    "\n",
    "A condition can also be created by combining a `GeotopUnits` selection with a boolean `DataArray`. For example, we can determine the thickness of the Dutch basal peat unit (`\"NUNIBA\"`), but only where the probability of voxels containing organic material is higher than 0.8."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "95217ed6",
   "metadata": {},
   "outputs": [],
   "source": [
    "thickness_basal_peat = geotop.gst.get_thickness(\n",
    "    strat_units.select_unit(\"NUNIBA\") & (geotop[\"kans_1\"] > 0.8)\n",
    ")\n",
    "thickness_basal_peat.plot.imshow(x=\"x\")"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "b07fd974",
   "metadata": {},
   "source": [
    "```{note}\n",
    "The boolean `DataArray` must be placed last when combined with a `GeotopUnits` instance. Otherwise, a `TypeError` is raised.\n",
    "```\n",
    "\n",
    "Since the results are `xarray.DataArray` objects, we can export them as GeoTIFFs using Rioxarray. This makes it easy to share the results and view them in GIS software. For example, let's export the Basal peat thickness result to a GeoTIFF."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "5df3f955",
   "metadata": {},
   "outputs": [],
   "source": [
    "thickness_basal_peat.rio.to_raster(\"thickness_basal_peat.tif\")"
   ]
